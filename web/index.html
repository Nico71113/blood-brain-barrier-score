Method

BBB Score = P(AroR) + P(HA) + 1.5 × P(MWHBN) + 2 × P(TPSA) + 0.5 × P(pKa). MWHBN = (HBA + HBD) / √MW.

Select the highest basic pKa ≥ 5; otherwise use the lowest acidic pKa ≤ 9. The neutral convention is 8.81.

Descriptors alone cannot identify a unique structure. Supply SMILES for 2D depiction.
